# Proteome Video — Reproducible Analysis Pipeline

Self-contained pipeline for the Proteome Video manuscript. Every step runs independently; all inputs, intermediates, and outputs are contained within this repository.

## Citation

Zhou, Z., Sun, R., Li, Z., Wang, S., Qian, L., Dai, Z., Zeng, L., Ma, K., Zhang, G., & Guo, T. (2026). *Minute-scale proteomics profiling resolves the chronological mechanics of yeast cell death*. LangTaoSha Preprint Server. https://doi.org/10.65215/LTSpreprints.2026.05.28.000257

## Data

The raw DIA-NN protein groups matrix is available at **PXD078576**. Download `20250610_wsy_PV_report.pg_matrix.tsv` and place it in the repository root. Step00 will automatically convert it to the pipeline format on first run — no manual preprocessing is needed.

The following additional files are already included in this repository:

| File | Purpose |
|------|---------|
| `gene_id_mapping.tsv` | Gene name → ENTREZID mapping |
| `ESR_gene_parameters.xls` | Canonical ESR gene reference |
| `Step04_Modeling/model/best_model.pth` | Pre-trained Latent ODE weights |

## Quick Start

```bash
cd Step00_Preprocess/src   && Rscript Step00_Preprocess.R
cd Step01_Overview/src      && Rscript Step01_Overview.R
cd Step02_Clustering/src    && Rscript Step02_Clustering.R
cd Step03_GAM/src           && Rscript Step03_GAM.R
cd Step04_Modeling/src      && python preprocess_data.py && python eval_fig4bc.py
cd Step05_Interpretation/src && python Step05_interpret.py && python Fig5b.py
```

**Prerequisites:** R (≥4.0), Python (≥3.9), plus the following packages:

- **R:** `tidyverse`, `mgcv`, `pheatmap`, `clusterProfiler`, `org.Sc.sgd.db`, `WGCNA`, `ggrepel`, `maSigPro`
- **Python:** `torch`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `scipy`, `torchdiffeq`

## Directory Layout

```
├── 20250610_wsy_PV_report.pg_matrix.tsv    # Raw DIA-NN export (download from PXD078576)
├── 20250610_PV_report.pg_matrix.csv        # Pipeline input (auto-generated by Step00)
├── gene_id_mapping.tsv                     # Gene name → ENTREZID
├── ESR_gene_parameters.xls                 # Canonical ESR gene list
├── README.md
│
├── Step00_Preprocess/     # Data cleaning & imputation
├── Step01_Overview/       # Fig.1 + EFig.1
├── Step02_Clustering/     # Fig.2 + EFig.2–3
├── Step03_GAM/            # Fig.3 + EFig.4
├── Step04_Modeling/       # Fig.4B/C
└── Step05_Interpretation/ # Fig.5 + EFig.5
```

Each step follows: `src/` (scripts), `figure/` (PDF figures), `output/` (intermediates). Step04 additionally has `model/` for pre-trained weights; Step03 and Step05 have `original/` for reference outputs.

## Pipeline Summary

| Step | Script(s) | Key Method |
|------|-----------|-------------|
| 00 — Preprocess | `Step00_Preprocess.R` | Quantile normalization → batch correction → KNN imputation |
| 01 — Overview | `Step01_Overview.R` | PCoA, t-SNE, PVCA, LOESS centroid distance |
| 02 — Clustering | `Step02_Clustering.R` (+ 2 Python helpers) | maSigPro clustering, WGCNA, GO/KEGG enrichment, ESR Fisher test |
| 03 — GAM | `Step03_GAM.R` (+ 1 Python helper) | GAM per protein, signed effect sizes, temporal KEGG GSEA |
| 04 — Modeling | `preprocess_data.py`, `eval_fig4bc.py` | Latent ODE inference (pre-trained model) |
| 05 — Interpretation | `Step05_interpret.py`, `Step05_GSEA.R`, `Fig5b.py` | Latent PCA, input gradients, signed saliency GSEA |

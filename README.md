# Proteome Video

This repository contains analysis code and metadata for a minute-scale DIA-MS proteomics study of regulated cell death in *Saccharomyces cerevisiae*. The project profiles yeast proteome dynamics at 1-minute resolution under lethal acetic acid and hydrogen peroxide stress and reconstructs temporal trajectories of stress adaptation, proteome remodeling, and irreversible cellular collapse.

Raw mass spectrometry data are deposited in PRIDE/ProteomeXchange. Processed matrices, sample metadata, and analysis scripts are provided here to support reproducibility of the manuscript.
